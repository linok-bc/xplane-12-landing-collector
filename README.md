# Installation

This package requires some dependencies that are installed via pip. XPPython comes with its own version of Python; we will use their bundled pip installer. The path to this file should be something like `PATH_TO_XPPLANE/Resources/plugins/XPPython3/lin_x64/python3.12/bin/python3`. Please be cognisant that Python's version may change.

```
cd "<PATH_TO_XPLANE>"
Resources/plugins/XPPython3/lin_x64/python3.12/bin/python3.12 -sm pip install \
> omegaconf
```
